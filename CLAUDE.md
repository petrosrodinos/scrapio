# Scrapio

Monorepo with two independent projects:

- `api/` — NestJS + TypeScript backend. Rules: `api/CLAUDE.md`.
- `app/` — React + TypeScript + HeroUI frontend. Rules: `app/CLAUDE.md`.

When working inside `api/` or `app/`, follow that directory's `CLAUDE.md` precisely for structure, naming, and coding patterns.
